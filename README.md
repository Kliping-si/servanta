# Servanta for Claude Code

Servanta gives Claude Code access to your monitored media archive, including web, print, radio,
television, and transcript coverage. It can search by keywords, concepts, sources, countries, topics,
authors, and date ranges; retrieve full articles; summarize results; and find coverage similar to a
selected article.

## Setup

Install and enable the plugin in Claude Code. You need internet access and a Servanta account with
permission to read your organization's monitored archive. The plugin connects to the hosted MCP
server at `https://servanta.ai/mcp`, so no local server or API key configuration is required. Complete
the Servanta sign-in flow if Claude Code asks you to authorize the connection.

## How to use it

Start a new Claude Code session after enabling the plugin, then ask for the coverage you need. For
example: “Find Servanta articles about renewable energy from the last 30 days,” “Summarize this
week's coverage of our company,” or “Find articles similar to this result.” Claude will call the
Servanta search and article-retrieval tools and include source names, publication dates, and links in
its answer.
